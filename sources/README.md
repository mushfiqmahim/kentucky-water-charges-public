# Sources

`catalog.csv` records 213 original evidence documents; `files/` contains 54 PSC orders. Another 158 originals are supplied through recorded host references, and one saved annual-report index lacks a verified original URL. The three previously withheld originals remain excluded. `access.csv` gives the path, URL, size, SHA-256, Git blob identity, analytical roles and access status for every document. The Knott compilation contains individual customer names; a Western Fleming monitoring filing contains bank-account identifiers; redistribution terms for the Kentucky affordability report remain unresolved.

Numerical reproduction uses compiled inputs without opening original documents. From the project root, `python src/verify_sources.py` separately verifies source references and every expected original's size, SHA-256 and Git blob identity. It writes `results/source_verification.json` and returns exit code 0 only for complete matching coverage, 2 for missing originals, or 1 for incorrect identities or invalid references. This distribution reports 54 verified and 159 missing originals. It never treats missing evidence as verified. See [reproduction instructions](../docs/reproduction.md).

Catalogue paths are relative to the project root. Cells containing arrays or objects use JSON. Source IDs, URLs, dates, citation pages and qualifications preserve the evidence behind the tariff/account registers and event classifications. Historical aliases identify where the evidence originated; they are not required directories. Identical source contents share one canonical file, with aliases retained as provenance.

`current_input_references` links sources to current event IDs and PDF pages. In `citation_contexts`, `register` and `record` identify the recorded assertion and `fields` retain its original values. Retrieval metadata may use `pages` for document length; citation-specific `pdf_page` fields identify referenced pages. Issue, service-effective, retrieval and billing dates are not interchangeable.

`cited_works.csv` covers the manuscript's 15 bibliography entries and distinguishes local evidence, full-text coverage and abstract/metadata-only coverage. A citation URL is not proof of complete text access. `unresolved_references.json` records missing or ambiguous references, including the failed Henry #2 report retrieval.

Original bytes have not been redacted, repaired or replaced. The catalogue's hashes and fixed validation reference remain the expected identities even for linked-only documents. Live host files can change; a new download must match the expected identity before being used for this version. Archived HTML navigation can point to unselected assets.

The source set is selective, not a complete PSC archive. Bundled files are official PSC administrative orders and their adopted appendices, recommended for distribution on the government-edicts basis described in the [U.S. Copyright Office Compendium, §313.6(C)(2)](https://www.copyright.gov/comp3/chap300/ch300-copyrightable-authorship.pdf). Utility-authored filings and saved institutional HTML are referenced instead of bundled where republication rights are unresolved. This recommendation does not extend to all Kentucky state works or all PSC-hosted files. It is not a comprehensive privacy clearance or a blanket license. [Evidence notes](../docs/evidence.md) explain the scientific qualifications and assistance/review scope.
